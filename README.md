# Student Performance Analysis Dashboard

## Project Overview
This project presents an interactive Power BI dashboard to analyze student academic performance. It provides insights into pass percentage, department-wise performance, subject-wise marks comparison, and student statistics.

## Tools Used
- Power BI
- Microsoft Excel / CSV

## Dashboard Features
- Total Students KPI
- Pass Percentage KPI
- Pass Students KPI
- Department-wise Student Performance
- Department-wise Pass Percentage
- Subject-wise Marks Comparison
- Final Result Analysis

## Key Insights
- Total Students: 520
- Pass Percentage: 65%
- Pass Students: 338
- Department-wise performance comparison
- Subject-wise marks analysis
